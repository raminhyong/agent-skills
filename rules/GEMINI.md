# ข้อมูลประจำเครื่องและผู้ใช้งาน (Antigravity Global Profile)

- **ชื่อผู้ใช้งานประจำเครื่อง**: **นายรามิล ปัญญพัทธ์** (สะกดว่า "ปัญญพัทธ์" เสมอ ห้ามสะกดเป็น ปัญญะพัฒน์ หรืออื่น ๆ)
- **ตำแหน่ง / วิทยฐานะ**: ครู วิทยฐานะครูชำนาญการพิเศษ กลุ่มสาระการเรียนรู้ภาษาไทย โรงเรียนพูลเจริญวิทยาคม
- **การจัดทำเอกสารภาษาไทย**: ให้ปฏิบัติตามสกิล `thai-doc` อย่างเคร่งครัด
  - การตัดคำภาษาไทยด้วย Zero-Width Space (`\u200b`) ต้องแทรกระหว่างคำอย่างถูกต้อง ห้ามแยกสระหรือวรรณยุกต์ออกจากพยัญชนะ
  - ปิดเส้นหยักแดงตรวจสะกดใน Word ด้วย `<w:noProof/>` และ `<w:lang w:val="th-TH"/>`
  - ใช้ระยะบรรทัด Zero Spacing (`space_before=0`, `space_after=0`, `line=240 dxa`) และฟอนต์ `TH Sarabun New`
  - ตารางต้องมี `<w:cantSplit/>` และ `<w:tblHeader/>`
- **การเลือกใช้เครื่องมือ ปลั๊กอิน และ Extension ร่วมกับ TypeSafe**:
  - เมื่อเริ่มต้นสร้างโปรเจกต์ หรือเจอปัญหาที่ซับซ้อน ให้ใช้กระบวนการคิดและตัดสินใจแบบ `typesafe-ai` ในการประเมินและคัดเลือกเครื่องมือ ปลั๊กอิน Extension, Add-on หรือ Skill ที่เหมาะสมที่สุด (ปฏิบัติตามแนวทางใน `tool_orchestration_typesafe.md`) โดยไม่เดาสุ่มและเลือกสิ่งที่ให้ประสิทธิภาพสูงสุดเสมอ
- **การอบรมออนไลน์และทำแบบทดสอบ**: ปฏิบัติตามสกิล `human-like-learner` อย่างเคร่งครัด
  - ห้ามเจาะระบบ หรือ bypass API หลังบ้านโดยเด็ดขาด ป้องกันบัญชีผู้ใช้ถูกระงับ (Ban)
  - ปล่อยวิดีโอเล่นตามปกติ และทำข้อสอบผ่านหน้าจอ UI/เมาส์คลิกเหมือนมนุษย์เท่านั้น
  - จัดเก็บเกียรติบัตรลงโฟลเดอร์ `เกียรติบัตร/` และบันทึกลง `README.md` เสมอ
- **คำสั่งลัดและการถอดรหัสระบบ (REA - Reverse Engineer Anything)**:
  - เมื่อผู้ใช้พิมพ์คำสั่ง `/REA` หรือ `/rea` หรือสั่งให้ "ใช้ REA", "แกะโค้ด", "ถอดรหัสโปรแกรม" ให้เปิดอ่านและปฏิบัติตามสกิล `rea` (`C:\Users\patti\.gemini\config\skills\rea\SKILL.md`) ทันที
  - มุ่งเน้นการถอดรหัสโครงสร้าง สถาปัตยกรรม โมเดลข้อมูล (Data Schema) และอัลกอริทึมของโปรแกรมภายนอกเพื่อสร้างระบบใหม่แบบ Clean-room Implementation เสมอ
- **คำสั่งลัดและการค้นหาภาพหลักฐาน (PicSeek - Targeted Photo Mining)**:
  - เมื่อผู้ใช้พิมพ์คำสั่ง `/picseek` หรือสั่งให้ "หาภาพ", "ค้นหารูป" ตามโฟลเดอร์ที่ชี้เป้า ให้เปิดอ่านและปฏิบัติตามสกิล `picseek` (`C:\Users\patti\.gemini\config\skills\picseek\SKILL.md`) ทันที
  - ดำเนินการสแกนเฉพาะโฟลเดอร์ที่ผู้ใช้ระบุ ตัดคำภาษาไทยด้วย PyThaiNLP และจับคู่ภาพเข้ากับตัวชี้วัดหรือหัวข้อรายงาน พร้อมรองรับการคัดลอกลงรายงานอัตโนมัติ
