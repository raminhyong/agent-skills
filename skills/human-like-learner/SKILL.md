## 🔍 โปรโตคอลสำรวจเว็บใหม่ (Site Discovery Protocol) — ใช้กับ**ทุก**แพลตฟอร์ม
สกิลนี้ต้องใช้ได้กับเว็บใหม่ที่ไม่เคยเห็น (KU MOOC, SkillLane, Chula MOOC, ThaiMOOC, สพฐ., Alison, Coursera, ระบบอบรมของมหาวิทยาลัย ฯลฯ) **ห้ามถือว่าพิกัดหรือโครงหน้าเว็บของเว็บใดเว็บหนึ่งเป็นค่ากลาง** — คำนวณใหม่ทุกครั้งจากภาพหน้าจอล่าสุด

ขั้นตอนมาตรฐานเมื่อเปิดเว็บใหม่:
1. **capture ภาพแรก** แล้วอ่านโครงกระดูกของหน้า: ชื่อหลักสูตร/บท, สารบัญหรือแถบความคืบหน้า (sidebar / stepper / “บทที่ x จาก y”), พื้นที่เนื้อหา, แถบปุ่มท้ายหน้า
2. **หาปุ่มหลัก (primary action) ของหน้านั้น** — โดยปกติมีปุ่มเดียวที่เด่น (สีทึบ) อยู่ล่างขวา/ล่างกลางของ content หรือมุมขวาบน; **อ่าน label ทุกครั้งก่อนกด** (Next / Continue / Submit / เริ่ม / ยืนยัน / ถัดไป)
3. **ระบุปุ่มอันตรายที่ห้ามกด**: ชำระเงิน/ซื้อเกียรติบัตร (Buy, Upgrade, Certify, ซื้อเลย), บัญชี (Logout, Account Settings), ลิงก์โฆษณา. ถ้าปุ่มหลักกับปุ่มอันตรายสีใกล้กัน ให้ยืนยันด้วย label + ตำแหน่งซ้ำก่อนคลิก
4. **หาตัวจับสถานะ (state marker)** เพื่อยืนยันว่าคลิกได้ผล: % ความคืบหน้า, เลขข้อ (ข้อ x/y), ชื่อบทที่ active
5. **บันทึก quirks ต่อเว็บแยกไฟล์** เป็น `references/site-notes-<domain>.md` — ห้ามเขียนพิกัดของเว็บหนึ่งไปปนกับอีกเว็บ เพราะ next site จะมีเลย์เอาต์คนละแบบ

หลักการที่คงที่ทุกเว็บ (ไม่ผูกกับแบรนด์):
- **คำนวณพิกัดสดจาก capture ล่าสุด** ทุกครั้ง; เปลี่ยนขนาดหน้าต่าง/ซูม/จอ → คำนวณใหม่
- **คลิกแล้ว capture ยืนยันทุกครั้ง**; ถ้าคลิก 2 ครั้งติดแล้วสถานะไม่เปลี่ยน ให้ re-derive ตำแหน่งใหม่ อย่าคลิกซ้ำจุดเดิม
- ปุ่มในเนื้อหาเว็บมักไม่โผล่ใน accessibility tree ของ Chrome → ใช้พิกัดจากภาพ; Chrome ไม่รับ scroll แบบ background → ใช้ `delivery_mode: foreground`
- โฆษณา/ป๊อปอัป: หา Close/×/ปิดในกรอบก่อน; ไม่มีก็กด Esc หรือรอ/เลื่อนผ่าน — **ห้ามกดสิ่งที่โฆษณาเสนอ**
- ข้อจำกัดเครื่องนี้: การพิมพ์ข้อความต้องอนุมัติผู้ใช้ → ข้อที่ต้องพิมพ์ตอบให้ใช้ Skip/ข้าม แล้วรายงานว่า skip ข้อไหน
- pacing: 1–3 วินาทีระหว่างคลิก, อ่าน/ฟังเนื้อหาก่อนกด Next ทุกหน้า, ไม่กดรัว

## ⚠️ กฎเหล็กความปลอดภัยบัญชีขั้นสูงสุด (Non-Negotiable Account Security Rules)
เมื่อได้รับมอบหมายให้ทำการอบรมออนไลน์ เรียนหลักสูตร หรือทำข้อสอบบนแพลตฟอร์มต่าง ๆ (เช่น KU MOOC, SkillLane, Chula MOOC, ThaiMOOC, สพฐ., ศธ. ฯลฯ):

1. **ห้ามเจาะระบบ หรือยิง API หลังบ้านโดยเด็ดขาด (Strict No-Bypass / No-Tampering)**:
   - ห้าม Inspect หา endpoint หลังบ้านเพื่อยิงข้ามบทเรียน
   - ห้ามเรียกใช้ JavaScript ฟังก์ชันภายในของระบบ (เช่น `updateTimeSpentStudy`, `completeTopic`, API bypass) เพื่อเร่งเวลาหรือปรับสถานะเรียนจบ
   - ห้ามดัดแปลงตัวแปรโครงสร้างบทเรียนของเว็บ
   - **เหตุผล**: แพลตฟอร์มการศึกษามีระบบดักจับพฤติกรรมผิดปกติ (Cheat Detection / Rate Limiting / Anomaly Detection) การ bypass จะทำให้บัญชีของผู้ใช้เสี่ยงโดนระงับ (Account Banned) หรือถูกเพิกถอนใบประกาศนียบัตร

2. **ทำทุกอย่างผ่านหน้าจอเหมือนมนุษย์ใช้งานจริง (Human-Like UI & Mouse Only)**:
   - **การดูวิดีโอ**: ปล่อยให้วิดีโอเล่นตามปกติบนหน้าจอตามเวลาจริง
   - **การนำทาง**: คลิกเมนู หรือปุ่มบนหน้าจอทีละขั้นตอนตามลำดับที่ระบบกำหนด
   - **การทำข้อสอบ**: อ่านคำถามและตัวเลือกจากหน้าจอ คิดวิเคราะห์คำตอบที่ถูกต้องตามหลักวิชาการ แล้วใช้เมาส์คลิกตัวเลือกทีละข้อ
   - **การส่งคำตอบ**: ตรวจทานความถูกต้องแล้วคลิกปุ่ม "ส่งคำตอบ" หรือ "ถัดไป" บนหน้าเว็บ

3. **การจัดเก็บเกียรติบัตรอัตโนมัติ (Automated Storage to Box)**:
   - เมื่อเรียนจบและทำแบบทดสอบผ่านเกณฑ์ ให้ดาวน์โหลดไฟล์เกียรติบัตร (PDF) จัดเก็บลงในโฟลเดอร์:
     👉 `C:\Users\patti\Box\เกียรติบัตร`
   - ตั้งชื่อไฟล์ให้ชัดเจนและเป็นระเบียบ เช่น `[ปี พ.ศ.]_[ชื่อหลักสูตร]_[ชื่อหน่วยงาน]_กมลวรรณ.pdf`
   - บันทึกประวัติ ผลคะแนน และวันที่สำเร็จลงใน `README.md` หรือบันทึกสรุปการอบรมทันที

4. **⏱️ สแตนด์บายโหมดประหยัดโทเคน (Idle & Watch Mode)**:
   - **ระงับการจับภาพหน้าจอ (No Screen Polling)**: ปิดการจับภาพหน้าจอและคำสั่งค้นหาข้อมูลทั้งหมดระหว่างดูวิดีโอ เพื่อประหยัดโทเคน 100%
   - **ไม่เจาะระบบ/ไม่ส่งคำขอซ้ำ**: ปล่อยวิดีโอบทเรียนเล่นตามธรรมชาติบนหน้าจอเบราว์เซอร์
   - **การส่งสัญญาณขั้นตอนถัดไป**: สังเกตหน้าจอหยุดขยับ/วิดีโอจบ หรือให้ผู้ใช้ส่งสัญญาณ จากนั้นจึงเข้าทำแบบทดสอบ (Post-test) และดาวน์โหลดเกียรติบัตรเข้า `C:\Users\patti\Box\เกียรติบัตร` ทันที
