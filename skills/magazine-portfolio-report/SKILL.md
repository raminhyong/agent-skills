# สกิลการสร้างพอร์ตโฟลิโอและรายงานผลการปฏิบัติงานแนวแม็กกาซีน (Magazine Portfolio & Performance Report Masterclass)

คู่มือและมาตรฐานการสร้าง **แฟ้มสะสมผลงาน (Teacher & Student Portfolio), เอกสารประเมินผลการปฏิบัติงาน (ว PA / ข้อตกลง PA), รายงานผลการดำเนินโครงการ/นวัตกรรม (SAR / Best Practice)** ที่พลิกโฉมจากเอกสารราชการแบบเดิม ๆ ให้กลายเป็น **"นิตยสารวิชาการร่วมสมัยระดับพรีเมียม (Contemporary Academic Magazine)"** ที่น่าอ่าน ผ่อนคลาย สวยงาม คมชัดระดับ 4K และทรงอิทธิพลต่อสายตาของคณะกรรมการผู้ประเมิน

---

## 💎 ปรัชญาและจุดยืนของระบบ (The Editorial Manifesto)

1. ❌ **ปฏิเสธ Canva และ Figma โดยเด็ดขาด (Strict No-Canva / No-Figma Policy):**
   * เทมเพลตสำเร็จรูปจำกัดความคิด มักขังเนื้อหาไว้ในกล่องแข็งทื่อ ("Card-in-a-Box Syndrome") มีปัญหาการตัดคำและเรนเดอร์สระ/วรรณยุกต์ไทย และส่งออกภาพแตก
   * ระบบของเราขับเคลื่อนด้วย **Programmatic HTML5/CSS3 Grid & Flexbox Engine** และเรนเดอร์ผ่าน **Playwright 4K/8K Retina Engine** คมชัดระดับสิ่งพิมพ์ออฟเซต ควบคุมพิกเซลด้วยคณิตศาสตร์
2. 🍃 **ความผ่อนคลายและพื้นที่หายใจ (The Luxury of Air):**
   * เอกสารรายงานที่ดีต้อง **"ไม่จัดแน่นจนอึดอัด"** แต่มีความผ่อนคลาย เป็นธรรมชาติ ด้วยการเปิดพื้นที่ว่าง (Intentional Whitespace / Negative Space) โอบล้อมเนื้อหา
3. 📖 **การเล่าเรื่องแบบนิตยสารสารคดีสากล (Editorial Storytelling):**
   * แทนที่จะใส่ตารางสี่เหลี่ยมเรียงเป็นพรืด เราใช้การร้อยเรียงแบบ Editorial Spread: มีป้ายหมวดหมู่ (Folio) $\rightarrow$ หัวเรื่องทรงพลัง (Display Title) $\rightarrow$ คำโปรยนำสะกดสายตา (Standfirst Deck) $\rightarrow$ ภาพคู่ที่สนทนากัน (Dual-Visual Dialogue) $\rightarrow$ สถิติเชิงปริมาณที่ชัดเจน (Minimal Metrics)
4. ⏳ **คุณภาพสูงสุดเหนือกาลเวลา (The Masterpiece Craftsmanship Protocol):**
   * **ไม่รีบร้อนและไม่ลดทอนคุณภาพเพื่อความเร็ว:** แม้ขั้นตอนจะต้องมีความซับซ้อนสูง (เช่น การรัน AI ไดคัตพื้นหลังด้วยโมเดล SOTA ในระบบ, การคำนวณจุดตัด Bounding Box, การจัดเลเยอร์ซ้อนกันหลายระนาบ Foreground/Midground/Background, การทำ CSS `shape-outside` เพื่อให้ข้อความไหลเลี้ยวหลบรูปทรงธรรมชาติ, และการเรนเดอร์ตรวจทาน 4K Retina) โทนี่จะทุ่มเททำอย่างประณีตที่สุด เพื่อให้ผลงานออกมาเป็น **"ผลงานระดับมาสเตอร์พีซ (Masterpiece Standard)"** เสมอ ตามเจตนารมณ์ของครูรามิล

## ⚠️ กฎเหล็กและมาตรฐานเชิงโครงสร้าง (Non-Negotiable Rules)

### 1. กฎการจัดวางภาพและเลเยอร์ซ้อนเหลื่อม 3 มิติ (Layered Depth & Organic Overlap)
เมื่อนำเสนอภาพกิจกรรม นวัตกรรม หรือหลักฐานเชิงประจักษ์:
* ❌ **หลุมพรางขังภาพในกล่องแข็งทื่อ (Card-in-a-Box Syndrome):**
  * ห้ามนำภาพทุกภาพไปใส่ในกล่องสี่เหลี่ยมสีขาวเรียงแถวทื่อ ๆ เหมือนแดชบอร์ดเว็บไซต์ เพราะจะทำลายบรรยากาศความเป็นนิตยสาร ทำให้ดูแน่น อึดอัด และขาดศิลปะ
* ✅ **สถาปัตยกรรมเลเยอร์ภาพซ้อนเหลื่อม (Organic Layered Architecture):**
  * **ภาพที่ 1 (The Visual Anchor - 60% - 65% Weight):** ภาพมุมกว้างเล่าบรรยากาศภาพรวม วางเป็นระนาบภาพหลักที่มีความลึก
  * **ภาพเจาะลึกซ้อนเหลื่อม (Layered Insets with Depth Shadows):** นำภาพโคลสอัปหรือภาพกลุ่มย่อยมา **ซ้อนเหลื่อม (Overlap) ข้ามขอบของภาพหลัก** ในบริเวณที่เป็นพื้นที่ปลอดภัย (เช่น ผิวโต๊ะ ท้องฟ้า หรือพื้นล่าง) โดยห้ามทับศีรษะหรือใบหน้าของตัวแบบเด็ดขาด
  * **เงามิติและความหรูหรา (Subtle Depth Shadows & Floating Badges):** ใช้กรอบขาวบางเฉียบร่วมกับเงาละมุนตา `box-shadow: 0 20px 45px rgba(26, 15, 17, 0.16)` พร้อมติดป้ายกำกับลอย (Floating Accent Pills) เชื่อมรอยต่อระหว่างเลเยอร์ ทำให้งานมีมิติ หน้าชัดหลังเบลอ (Foreground, Midground, Background) อย่างเป็นธรรมชาติ
  * **บทสนทนาเชิงปรัชญา (Dual Perspective Bridge):** แนบข้อความสะท้อนคิด (Reflection/Insight) สั้น ๆ คม ๆ ใต้ภาพเจาะ เพื่อเชื่อมโยง "กระบวนการภาพใหญ่" สู่ "ผลลัพธ์เชิงลึก"

---

### 2. กฎการตรวจจับและคุ้มครองตัวแบบสำคัญ (Subject Saliency & Bounding Box Integrity)
* ❌ **ห้ามครอปตัดโดนส่วนสำคัญของผู้ปฏิบัติงานหรือหลักฐาน:** การตัดโดนศีรษะคน หน้าตานักเรียน ใบประกาศ หรือผลงานสำคัญ ถือเป็นข้อผิดพลาดร้ายแรง
* ✅ **ตรวจจับด้วย AI Saliency ก่อนวางเลย์เอาต์:**
  * ใช้สคริปต์ `detect_subject.py` (โมเดล BRIA-RMBG ในระบบ) สแกนหา Bounding Box $[X_{\min}, X_{\max}, Y_{\min}, Y_{\max}]$ ของบุคคลและวัตถุสำคัญ
  * **Full-Body / Full-Action Guarantee:** ตัวแบบครู นักเรียน หรือผลงานต้องปรากฏสมบูรณ์ 100%
  * เส้นไล่เฉดสีดำ (Vignette Mask) ต้องอยู่เฉพาะในพื้นที่ว่างรอบนอก (ยอดฝ้าเพดาน ท้องฟ้า พื้นห้อง) **ห้ามรุกล้ำเข้าไปในตัวแบบเด็ดขาด**

---

### 3. กฎขนาดฟอนต์สัมพัทธ์ความสูงแคนวาส (The 1.2% Canvas Height Rule)
$$\text{Minimum Font Floor} = \text{Canvas Height} \times 1.2\%$$

* **มาตรฐานหลัก: แคนวาสแนวตั้ง A4 Portrait ($1400 \times 1980\text{ px}$):**
  * ฟอนต์เล็กสุด (Footer Bar, Spec Tag, Folio Issue, Figure Captions): **$\ge 24\text{px}$** ($1980 \times 1.2\% = 23.76\text{px}$)
  * เนื้อหาบรรยายผลงาน (Body Text / Evidence Descriptions): **$26\text{px} - 28\text{px}$**
  * คำโปรยนำและหัวข้อย่อย (Standfirst Deck / Subtitles): **$32\text{px} - 38\text{px}$**
  * ตัวเลขสถิติ / ผลสัมฤทธิ์เด่น (Quantitative Metrics): **$40\text{px} - 52\text{px}$**
  * พาดหัวเรื่องนิตยสาร (Hero Display Title): **$105\text{px} - 125\text{px}$**
* **มาตรฐานเสริม: แคนวาสแนวนอน 16:9 Landscape Spread ($1920 \times 1080\text{ px}$):**
  * ฟอนต์เล็กสุด: **$\ge 16\text{px}$**
  * เนื้อหาบรรยาย: **$18\text{px} - 22\text{px}$**
  * พาดหัวหลัก: **$90\text{px} - 110\text{px}$**

---

### 4. กฎการเลือกคู่ฟอนต์และการตัดขอบ (Typography & Distinct Stroke Armor)
* ❌ **ห้ามใช้ `TH Sarabun New` ทำหน้าปกหรือหัวข้อแฟ้มสะสมงานเด็ดขาด:** เพราะให้ความรู้สึกเป็นหนังสือราชการธุรการที่น่าเบื่อ
* ✅ **ชุดคู่ฟอนต์แนะนำสำหรับรายงานแนวแม็กกาซีน:**
  * **พาดหัวหลักวิชาการสไตล์นิตยสาร:** `Kanit` (Bold / Black) หรือ `Prompt` (Bold / ExtraBold) หรือ `Pridi` (Serif ทรงคุณค่า)
  * **ป้ายกำกับ หัวข้อย่อย และตัวเลขสถิติ:** `Space Grotesk`, `Plus Jakarta Sans`
  * **เนื้อหาบรรยายภาษาไทย:** `Noto Sans Thai` (Regular / Medium) หรือ `Prompt` (Regular)
* 🛡️ **เทคนิค Distinct Stroke & Radiance Glow:**
  ```css
  paint-order: stroke fill;
  -webkit-text-stroke: 2px rgba(12, 7, 4, 0.95);
  text-shadow: 
    0 0 2px #000, 0 0 4px #000,
    0 0 25px rgba(217, 90, 43, 0.6),
    0 4px 18px rgba(0, 0, 0, 0.95);
  ```

### 5. จานสีสไตล์นิตยสารระดับพรีเมียม (Editorial Color Palettes)

1. 🍂 **Terracotta Earth & Warm Obsidian (แนะนำ - ผ่อนคลาย เป็นธรรมชาติ):**
   * Background: Deep Espresso Obsidian (`#0C0704` ถึง `#1A0F09`)
   * Accents: Burnt Sienna (`#D95A2B`), Desert Amber (`#E6A15C`), Warm Quartz (`#FED7AA`)
   * Text: Pure White (`#FFFFFF`) และ Warm Sand (`#FFF7ED`)
2. 🌊 **Sapphire Executive & Deep Navy (ทางการ ผู้บริหาร ทรงภูมิ):**
   * Background: Midnight Navy (`#030712` ถึง `#0A1128`)
   * Accents: Electric Cyan (`#38BDF8`), Sapphire Blue (`#2563EB`), Ice Frost (`#BAE6FD`)
3. 🌿 **Emerald Wisdom & Forest Onyx (สิ่งแวดล้อม การเรียนรู้ ยั่งยืน):**
   * Background: Dark Spruce Onyx (`#030B07` ถึง `#061A0E`)
   * Accents: Vivid Emerald (`#10B981`), Mint Glow (`#6EE7B7`), Champagne Gold (`#FACC15`)

### 6. องค์ประกอบเอกลักษณ์แบบนิตยสาร (Editorial Anatomy Elements)

1. **Header Folio:**
   `<div class="editorial-folio"><span class="folio-pill">PORTFOLIO EDITION</span><span class="folio-rule"></span><span class="folio-issue">VOL. 01 • PERFORMANCE RECORD</span></div>`
2. **Editorial Standfirst (Deck):**
   ข้อความสรุปเป้าหมายหรือปรัชญาการทำงาน 2–3 บรรทัด คั่นด้วยเส้นแถบสีหนา 4px–5px ด้านซ้าย (Border-left accent)
3. **Figure Code Tags:**
   กำกับภาพทุกภาพด้วยรหัสสารคดี เช่น `[FIG. 01 : ACTIVE INQUIRY]` และ `[FIG. 02 : STUDENT ARTIFACT]`
4. **Minimalist Stat Pills (สถิติเชิงประจักษ์):**
   กล่องสถิติแบบ Frosted Glass เน้นตัวเลขใหญ่สะดุดตาพร้อมหน่วยวัดชัดเจน
5. **Author & Institutional Footer Bar:**
   แถบเครดิตล่างสุดแสดงชื่อผู้จัดทำ โรงเรียน และสเปกของหน้าเอกสารแบบมีช่องไฟกว้างสง่างาม

## 🤖 ลูปการทำงานแบบทีมเอเจนต์อัตโนมัติ (The 4-Stage Sub-Agent Loop)

เพื่อให้กระบวนการสร้างนิตยสารมีประสิทธิภาพสูงสุด สกิลนี้ขับเคลื่อนด้วยทีม Sub-Agents 4 ขั้นตอน:

1. **`editorial-content-agent` (Content Strategist):**
   * วิเคราะห์ข้อความดิบราชการ / ว PA / SAR สกัด **Golden Metrics** (วันที่, ช่วงเวลา, สถิติ)
   * ร้อยเรียงเป็น Display Title, Standfirst Deck, 3 เสาหลักเชิงยุทธศาสตร์, และ Reflective Quote
2. **`editorial-visual-director` (Visual & Layering Director):**
   * สกัดและแยกภาพคู่ในเอกสาร รันโมเดล `detect_subject.py` หา Bounding Box เพื่อคุ้มครองตัวแบบ
   * ออกแบบ **Layered Depth Architecture**: จัดวาง Macro Anchor และคำนวณพิกัด Overlapping Insets ให้ซ้อนเหลื่อมอย่างมีมิติ โดยไม่ทับใบหน้าคน
3. **`editorial-code-architect` (Tony Coordinator):**
   * แปลงผลงานของเอเจนต์เนื้อหาและภาพ เป็นโค้ด HTML5/CSS3 บนแคนวาส A4 Portrait ($1400 \times 1980\text{ px}$)
   * กำกับ **กฎ 1.2% Canvas Height Rule** ($\ge 24\text{px}$) และระดับความเข้มสี 1-2-3
4. **`editorial-qa-inspector` (Visual QA Auditor):**
   * เรนเดอร์ 4K Retina PNG & Vector PDF ผ่าน Playwright
   * ใช้สายตา AI ตรวจสอบการตัดคำ, การซ้อนทับของเลเยอร์, ความสมดุลของพื้นที่หายใจ (The Luxury of Air) และอนุมัติงานส่งมอบ

## 🛠️ เครื่องมืออัตโนมัติประจำสกิล (Built-in Tooling)

* **สคริปต์ตรวจจับวัตถุและบุคคลสำคัญ (Saliency Detection):**
  `python scripts/detect_subject.py <path-to-image>`
* **สคริปต์ไดคัตและสกัดตัวแบบโปร่งใสระดับ SOTA (AI Subject Cutout):**
  `python scripts/cutout_subject.py <path-to-image> <path-to-output.png> [--trim]`
* **สคริปต์เรนเดอร์เอกสาร 4K Retina PNG & Vector PDF (Playwright):**
  `node render_report.mjs`
