# ข้อมูลผู้ใช้งานประจำเครื่อง (User Profile)

## ข้อมูลส่วนบุคคลและชื่อ-สกุล
- **ชื่อ-สกุล**: **นายรามิล ปัญญพัทธ์** (สะกด: ป-ั-ญ-ญ-พ-ั-ท-ธ-์)
  - ⚠️ **กฎเหล็กเรื่องชื่อ**: ทุกเอกสาร รายงาน แผนการสอน ID PLAN และโค้ด ต้องสะกดชื่อผู้ใช้ว่า **นายรามิล ปัญญพัทธ์** เสมอ **ห้ามสะกดผิดเป็น ปัญญะพัฒน์ หรือ ปัญญาพัทธ์ หรืออื่น ๆ โดยเด็ดขาด**
- **ตำแหน่ง**: ครู
- **วิทยฐานะ**: ครูชำนาญการพิเศษ
- **กลุ่มสาระการเรียนรู้**: ภาษาไทย
- **หน่วยงาน / สถานศึกษา**: โรงเรียนพูลเจริญวิทยาคม สำนักงานเขตพื้นที่การศึกษามัธยมศึกษาสมุทรปราการ
- **บทบาทหน้าที่เพิ่มเติม**:
  - หัวหน้ากลุ่มสาระการเรียนรู้ภาษาไทย
  - หัวหน้างานประกันคุณภาพการศึกษา (IQA AWARD / นโยบาย 10 ค)
  - กรรมการงานพัฒนาหลักสูตรสถานศึกษา
  - กรรมการงานวิจัยและพัฒนานวัตกรรมทางการศึกษา
  - วิทยากรภายนอกสถานศึกษา (เช่น มหาวิทยาลัยราชภัฏจันทรเกษม)

## มาตรฐานการจัดทำเอกสารภาษาไทย (Thai Document Standards)
ให้ใช้แนวทางปฏิบัติจากสกิล `thai-doc` เสมอ:
1. **การตัดคำด้วย Zero-Width Space (`\u200b`)**:
   - แทรก `\u200b` เฉพาะระหว่างรอยต่อของคำ (`word_tokenize`)
   - ⚠️ ห้ามแทรกระหว่างพยัญชนะกับสระบน (ิ, ี, ึ, ื, ั), สระล่าง (ุ, ู), วรรณยุกต์ (่, ้, ๊, ๋) และทัณฑฆาต (์) โดยเด็ดขาด
2. **การปิดเส้นหยักตรวจสะกดสีแดง (Proofing Suppression)**:
   - เพิ่ม `<w:noProof/>` และ `<w:lang w:val="th-TH"/>` ในทุก `<w:rPr>`
3. **ระยะบรรทัด (Zero Spacing Rule)**:
   - `space_before = 0 pt`
   - `space_after = 0 pt`
   - `line_spacing = 1.0 เท่า (240 dxa)`
4. **ฟอนต์หลัก**: `TH Sarabun New`
5. **โครงสร้างตาราง**:
   - แถวแรกต้องมี `<w:tblHeader/>`
   - ทุกแถวต้องมี `<w:cantSplit/>` ป้องกันแถวแตกข้ามหน้า

## มาตรฐานการจัดทำการ์ดเกมและสื่อการสอน (Card & Print Standards)
1. ⚠️ **กฎเหล็กการส่งออก PDF**: **ห้ามทำไฟล์ PDF แบบ 1 การ์ดต่อ 1 หน้า A4 โดยเด็ดขาด** 
   - ไฟล์ PDF สำหรับการ์ดเกมต้องจัดวางลงแผ่นพิมพ์ A4 (Print Sheets) แบบหลายใบต่อหน้าเสมอ (เช่น 9 ใบต่อหน้า A4 แนวตั้ง หรือสัดส่วนที่เหมาะสม)
   - ต้องใช้พื้นที่หน้ากระดาษให้คุ้มค่าที่สุด (Maximize printable area)
   - ต้องมีเส้นประช่วยตัด (Dashed cut lines) ที่เรียบร้อยระหว่างการ์ดทุกใบ
2. **ไฟล์ภาพการ์ดรายใบ**: สามารถส่งออกเป็นไฟล์รูปภาพ (PNG/JPG) แยกโฟลเดอร์ตามชุดได้ แต่ไฟล์เอกสาร PDF พร้อมพิมพ์ต้องเป็น Print Sheets เสมอ

## มาตรฐานการอบรมออนไลน์และทำแบบทดสอบ (Online Training & Human Emulation Standards)
ให้ปฏิบัติตามสกิล `human-like-learner` อย่างเคร่งครัด:
1. ⚠️ **ห้ามเจาะระบบ หรือ Bypass API หลังบ้านโดยเด็ดขาด**: ห้ามยิง API ข้ามเวลา ห้ามเรียก internal JS functions (เช่น `updateTimeSpentStudy`, `completeTopic`) ป้องกันบัญชีผู้ใช้ถูกระงับ (Ban)
2. **ปฏิสัมพันธ์ผ่าน UI เสมือนมนุษย์เท่านั้น**: ปล่อยคลิปวิดีโอเล่นตามปกติ ใช้เมาส์คลิกตัวเลือกข้อสอบทีละข้อ และกดส่งผ่านปุ่มบนหน้าจอ
3. **การจัดเก็บเกียรติบัตร**: ดาวน์โหลดไฟล์ PDF เก็บเข้าโฟลเดอร์ `เกียรติบัตร/` และอัปเดต `README.md` ทันทีที่ทำสำเร็จ

## มาตรฐานการถอดรหัสระบบและวิศวกรรมย้อนกลับ (Reverse Engineering & REA Standards)
ให้ปฏิบัติตามสกิล `rea` อย่างเคร่งครัด:
1. **คำสั่งลัด `/REA` หรือ `/rea`**: เมื่อผู้ใช้พิมพ์คำสั่ง ให้เข้าสู่โหมดวิเคราะห์และถอดรหัสแอปพลิเคชัน เว็บไซต์ หรือไฟล์ไบนารีทันที
2. **หลักการ Clean-room Reimplementation**: แกะเฉพาะโครงสร้าง สถาปัตยกรรม โมเดลข้อมูล (Data Schema) และอัลกอริทึม เพื่อนำมาเขียนโค้ดขึ้นใหม่ในโปรเจกต์ของเรา ปราศจากการคัดลอกโค้ดที่มีลิขสิทธิ์
3. **การทำงานแบบ Local Isolation**: สกัด วิเคราะห์ และดีคอมไพล์บนเครื่อง Local ห้ามยิง Payload โจมตีระบบภายนอก

---

## มาตรฐานการค้นหาภาพหลักฐานเจาะจงโฟลเดอร์ (PicSeek Standards)
ให้ปฏิบัติตามสกิล `picseek` อย่างเคร่งครัด:
1. **คำสั่งลัด `/picseek`**: เมื่อผู้ใช้สั่งค้นหาภาพ ให้เจาะจงเฉพาะโฟลเดอร์ Path ที่ผู้ใช้ชี้เป้า ห้ามสแกนทั้งดิสก์
2. **การตัดคำภาษาไทย**: ใช้ `PyThaiNLP (newmm)` ตัดคำชื่อไฟล์และโฟลเดอร์บริบท
3. **การนำภาพเข้าเอกสาร**: คัดลอกและปรับสัดส่วนภาพลงช่อง `evidence_images/` ตามเกณฑ์สัดส่วน A4 (7.7 cm แนวนอน หรือ 4.5 cm แนวตั้ง)

## มาตรฐานหลักสูตรและการวัดประเมินผลกลุ่มสาระการเรียนรู้ภาษาไทย (Thai Curriculum Invariants)
1. **รายวิชาพื้นฐาน -> ใช้ "ตัวชี้วัด" (Indicators) เท่านั้น**:
   - อิงหลักสูตรแกนกลางการศึกษาขั้นพื้นฐาน พ.ศ. 2551 (และฉบับปรับปรุง)
   - รหัสและข้อความถูก **ล็อกเฉพาะตายตัว (Locked Codes)** จากกระทรวงศึกษาธิการ เช่น `ท 1.1 ม.1/1`, `ท 4.1 ม.1/3` ห้ามดัดแปลงข้อความ ห้ามตัดทอน หรือประดิษฐ์รหัสใหม่เอง
   - หัวตารางทุกจุดในระบบและเอกสาร (โครงสร้างรายวิชา, กำหนดการสอนรายสัปดาห์, แผนการวัดผล) ต้องระบุเป็น **"ตัวชี้วัด"** เสมอ
2. **รายวิชาเพิ่มเติม -> ใช้ "ผลการเรียนรู้" (Learning Outcomes) เท่านั้น**:
   - อิงหลักสูตรสถานศึกษา โรงเรียนพูลเจริญวิทยาคม ตามจุดเน้นกลุ่มสาระการเรียนรู้ภาษาไทย
   - ตัวเลขกำกับเป็นเพียงลำดับข้อ ไม่ใช่รหัสล็อกตายตัว สามารถวางสลับกับข้อความได้
   - มีความยืดหยุ่นสูง (Flexible & Agile) ผ่านการประเมิน ทบทวน และปรับปรุงในแต่ละปีการศึกษา สามารถปรับแก้ข้อความ ลด หรือเพิ่มจำนวนผลการเรียนรู้ได้ตามความเหมาะสม
   - หัวตารางทุกจุดในระบบและเอกสาร ต้องระบุเป็น **"ผลการเรียนรู้"** เสมอ
3. **การจัดกึ่งกลางตารางกำหนดการสอนรายสัปดาห์ (Weekly Table Alignment)**:
   - คอลัมน์ `ชั่วโมงที่`, `หน่วยการเรียนรู้ที่`, `ตัวชี้วัด` / `ผลการเรียนรู้`, และ `คะแนน` ต้อง **จัดกึ่งกลาง (Center)** เสมอ
   - คอลัมน์ `สาระการเรียนรู้` และ `การประเมินผล` จัดชิดซ้าย (Left) ตามแบบฟอร์มเอกสารวิชาการ
4. **มาตรฐานหน้าปกโครงการจัดการเรียนรู้ (Cover Page Layout)**:
   - ตราสัญลักษณ์ / โลโก้โรงเรียนพูลเจริญวิทยาคม: อยู่บนสุด จัดกึ่งกลางหน้ากระดาษ (Center)
   - ระยะเว้นบรรทัดก่อนชื่อครูผู้สอน (หน้าชื่อ): เคาะ 2 บรรทัดว่าง (2 blank lines)
   - ระยะเว้นบรรทัดก่อนกลุ่มสาระการเรียนรู้ (หน้ากลุ่มสาระ...): เคาะ 2 บรรทัดว่าง (2 blank lines)
5. **มาตรฐานหัวตารางหน้า 3 โครงสร้างรายวิชา (3-Column Metadata Table)**:
   - ใช้เทคนิค **ตาราง 3 คอลัมน์ไร้เส้นขอบ (Borderless Table)** เพื่อป้องกันปัญหาข้อความหรือระยะแท็บ (Tab stops) เด้งตกบรรทัด
   - **แถวที่ 1**: คอลัมน์ 1 ชิดซ้าย (`รหัสวิชา ...`) | คอลัมน์ 2 จัดกึ่งกลาง (`วิชา ...`) | คอลัมน์ 3 ชิดขวา (`ระดับชั้น ...`)
   - **แถวที่ 2**: คอลัมน์ 1 ชิดซ้าย (`ภาคเรียนที่ ... ปีการศึกษา ...`) | คอลัมน์ 2 จัดกึ่งกลาง (`เวลา ... ชั่วโมง`) | คอลัมน์ 3 ชิดขวา (`จำนวน ... หน่วยกิต`)
