# สกิลการอบรมออนไลน์และการทำแบบทดสอบแบบจำลองพฤติกรรมมนุษย์ (Human-Like Online Learner)

## ⚠️ กฎเหล็กความปลอดภัยบัญชีขั้นสูงสุด (Non-Negotiable Account Security Rules)
เมื่อผู้ใช้มอบหมายให้ทำการอบรมออนไลน์ เรียนหลักสูตร หรือทำข้อสอบบนแพลตฟอร์มต่าง ๆ (เช่น KU MOOC, SkillLane, Chula MOOC, ThaiMOOC ฯลฯ):

1. **ห้ามเจาะระบบ หรือยิง API หลังบ้านโดยเด็ดขาด (Strict No-Bypass / No-Tampering)**:
   - ห้าม Inspect หา endpoint หลังบ้านเพื่อยิงข้ามบทเรียน
   - ห้ามเรียกใช้ JavaScript ฟังก์ชันภายในของระบบ (เช่น `updateTimeSpentStudy`, `completeTopic`, API bypass) เพื่อเร่งเวลาหรือปรับสถานะเรียนจบ
   - ห้ามดัดแปลงตัวแปรโครงสร้างบทเรียนของเว็บ
   - **เหตุผล**: แพลตฟอร์มการศึกษามีระบบดักจับพฤติกรรมผิดปกติ (Cheat Detection / Rate Limiting / Anomaly Detection) การ bypass จะทำให้บัญชีของผู้ใช้เสี่ยงโดนระงับ (Account Banned) หรือถูกเพิกถอนใบประกาศนียบัตร

2. **ทำทุกอย่างผ่านหน้าจอเหมือนมนุษย์ใช้งานจริง (Human-Like UI & Mouse Only)**:
   - **การดูวิดีโอ**: ปล่อยให้วิดีโอเล่นตามปกติบนหน้าจอตามเวลาจริง
   - **การนำทาง**: คลิกเมนู หรือปุ่มบนหน้าจอทีละขั้นตอนตามลำดับที่ระบบกำหนด
   - **การทำข้อสอบ**: อ่านคำถามและตัวเลือกจากหน้าจอ คิดวิเคราะห์คำตอบที่ถูกต้องตามหลักวิชาการ แล้วใช้เมาส์คลิกตัวเลือกทีละข้อ
   - **การส่งคำตอบ**: ตรวจทานความถูกต้องแล้วคลิกปุ่ม "ส่งคำตอบ" หรือ "ถัดไป" บนหน้าเว็บ

3. **การจัดเก็บเกียรติบัตรอัตโนมัติ**:
   - เมื่อเรียนจบและทำแบบทดสอบผ่านเกณฑ์ ให้ดาวน์โหลดไฟล์เกียรติบัตร (PDF) จัดเก็บลงในโฟลเดอร์ `เกียรติบัตร/` ของงานเสมอ
   - บันทึกประวัติและผลคะแนนลงใน `README.md` ทันทีหลังสำเร็จ

4. **⏱️ สแตนด์บายโหมดประหยัดโทเคน (Idle & Watch Mode)**:
   - **ระงับการจับภาพหน้าจอ (No Screen Polling)**: ปิดการจับภาพหน้าจอและคำสั่งค้นหาข้อมูลทั้งหมดระหว่างดูวิดีโอ เพื่อประหยัดโทเคน 100%
   - **ไม่เจาะระบบ/ไม่ส่งคำขอซ้ำ**: ปล่อยวิดีโอบทเรียนเล่นตามธรรมชาติบนหน้าจอเบราว์เซอร์
   - **การส่งสัญญาณขั้นตอนถัดไป**: สังเกตหน้าจอหยุดขยับ/วิดีโอจบ หรือให้ผู้ใช้ส่งสัญญาณ จากนั้นจึงเข้าทำแบบทดสอบ (Post-test) และดาวน์โหลดเกียรติบัตรทันที
