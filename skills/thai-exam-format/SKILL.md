# จัดฟอร์แมตเอกสารข้อสอบ โรงเรียนพูลเจริญวิทยาคม

แปลงข้อสอบดิบ (docx/json/ข้อความ) ให้เป็นรูปเล่มมาตรฐานโรงเรียน: ปก + ตาราง
มาตรฐาน/ตัวชี้วัด + ข้อสอบ + ตัวเลือก + บล็อกลงชื่อ ตามแบบ `Master.pdf`
ข้อมูลตัวอย่างจริง (question bank + ไฟล์ผลลัพธ์มาตรฐาน) อยู่ใน `examples/`

## When to Use (เมื่อไหร่ใช้)

- จัดรูปเล่มข้อสอบวัดผลกลางภาค/ปลายภาค (รายวิชาพื้นฐาน หรือ เพิ่มเติม)
- แก้ข้อสอบที่ฟอร์แมตเพี้ยน (ฟอนต์เด้ง ตัวเลือกไม่ตรงคอลัมน์ ข้อขาดหน้า)
- ตรวจงานฟอร์แมตข้อสอบก่อนส่งฝ่ายวิชาการ

ไม่ใช้กับ: เขียนเนื้อหาข้อสอบใหม่ · เฉลย/วิเคราะห์ข้อสอบ · บันทึกส่งข้อสอบ (→ `thai-official-memo`)

## Prerequisites

- รันสคริปต์ด้วย `py -3.12` เท่านั้น (มี `python-docx 1.2.0` / `pythainlp 5.3.7` / `pymupdf 1.28.2`) — python 3.14 ของ Hermes ไม่มี python-docx
- โลโก้โรงเรียน: `assets/school-logo.jpg`
- ตัวอย่าง: `examples/Job03.json` (39 ข้อ ตัวเลือก ก–ง) และ `examples/Job03_Formatted.docx` (ผลลัพธ์มาตรฐาน)

## ค่าหน้ากระดาษและฟอนต์

- `TH Sarabun New` 16 pt · ตั้งที่ `w:docDefaults` + สไตล์ `Normal` ครบ `ascii/hAnsi/cs/eastAsia` กัน Word เด้งฟอนต์
- **เลขอารบิกเท่านั้น** ทั้งเลขข้อ เลขตัวเลือก เลขหน้า เลขในตาราง และตัวเลขในเนื้อหา (ห้ามเลขไทย)
- Line spacing 1.0 · Space before/after 0 pt — ยกเว้นคำชี้แจงใต้เส้นกั้น `6 pt`
- Margins: บน 0.5" · ล่าง 0.5" · ซ้าย 0.7" · ขวา 0.8"
- เลขหน้าเริ่ม `1` ที่หน้าปก · TH Sarabun New 16 pt **Bold** · กึ่งกลาง header รูปแบบ `- 1 -`

## หน้าปก (หน้า 1)

1. โลโก้โรงเรียนกึ่งกลาง (`assets/school-logo.jpg`) → `โรงเรียนพูลเจริญวิทยาคม` Bold 16 pt กึ่งกลาง
2. ตารางหัวข้อสอบ 3 คอลัมน์ **เส้นขอบล่องหน** (ซ้ายชิดซ้าย / กลางกึ่งกลาง / ขวาชิดขวา) + เส้นทึบหนา 0.3 มม. (`w:sz="6"`) ใต้แถวที่ 3
3. คำชี้แจง Bold 16 pt · Space before 6 pt
4. ตารางสรุป 3 คอลัมน์ กว้าง 5.5" กึ่งกลาง:
   - คอลัมน์ 1: `มาตรฐานการเรียนรู้/ตัวชี้วัด` (พื้นฐาน) หรือ `ผลการเรียนรู้` (เพิ่มเติม) — หัวตารางกึ่งกลาง bold / เนื้อหาชิดซ้าย + left cell margin 100 dxa
   - คอลัมน์ 2: `ข้อสอบข้อที่` (กึ่งกลาง bold) · รายการเลขข้อกึ่งกลาง
   - คอลัมน์ 3: `หมายเหตุ` (กึ่งกลาง bold)
5. บล็อกลงชื่อ — เคาะ 10 วรรคหน้าชื่อในวงเล็บ `( ... )` เสมอ
   - แถวผู้ออกข้อสอบคู่: 2 คอลัมน์กว้าง 3.35" · `ลงชื่อ` + 40 จุด + เว้น 1 เคาะ + `ผู้ออกข้อสอบ` · space before 0
   - ตำแหน่งเดี่ยว (แถว 2–4): ผสาน 2 คอลัมน์ · `left_indent = 1.1"` · `ลงชื่อ` + 56 จุด + เว้น 1 เคาะ + ตำแหน่ง · space before 6 pt
6. Page break หลังบล็อกลงชื่อ → ข้อสอบเริ่มหน้า 2

## เนื้อหาข้อสอบ

- บรรทัดแรกหน้า 2: `คำสั่ง จงเลือกคำตอบที่ถูกต้องที่สุดเพียงคำตอบเดียว` (คำว่า `คำสั่ง` bold)
- หัวข้อมาตรฐาน/ผลการเรียนรู้: ธรรมดา ชิดซ้าย
  - ต่อเนื่องบนหน้าเดิม → space before **16 pt** · มาตรฐานติดกัน (ใช้บทอ่านร่วม) → **0 pt** · ขึ้นหน้าใหม่หรือหัวแรกใต้คำสั่ง → **0 pt**
  - ปิดท้ายด้วยช่วงเลขข้อที่คำนวณเองเสมอ `(ข้อ 1 - 4)` หรือ `(ข้อ 8)` — ไม่เชื่อว่าไฟล์ต้นฉบับพิมพ์มาถูก
  - วิชาเพิ่มเติม: **ห้าม**ใส่ `-` หรือ `—` หลัง `ผลการเรียนรู้ที่ ...`
- ข้อความนำบทอ่าน/รูปภาพ (`อ่านอินโฟกราฟิกต่อไปนี้แล้วตอบคำถามข้อที่ 9-10`) → **Bold**
- ตัวคำถามชิดซ้าย (`left_indent = 0`) · คำเชิงปฏิเสธ/ยกเว้น bold เฉพาะในคำถาม: ไม่, ไม่ใช่, ไม่มี, ไม่ปรากฏ, ไม่เหมาะสม, ไม่จำเป็น, ไม่ถูกต้อง, มิได้, ยกเว้น (ห้าม bold ในบทอ่าน)
- ข้อความบทอ่าน/ประโยคเรียงลำดับ เคาะบรรทัดใหม่ใต้คำถาม เยื้อง 0.4" · ตัวเลือกย่อย `(ก)-(ง)` เยื้อง 0.2"
- บทอ่านร้อยแก้ว first line indent 0.5" (รวม `(1)-(4)` ในบทอ่าน) · ร้อยกรอง left indent 1.0" + tab stop วรรคหลัง 3.2"
- รูปภาพกึ่งกลาง กว้าง ~4.5"
- เฉลยท้ายเล่ม (ถ้ามี): `เฉลย (สำหรับครู)` bold ชิดซ้าย

## ตัวเลือก

เยื้อง 0.2" ด้วย `left_indent` — **ห้ามใช้ `\t` นำหน้า** · เรียงจากสั้นไปยาวเสมอ

| รูปแบบ | เงื่อนไข | Tab stop |
|---|---|---|
| 1 | ตัวเลือกยาว 4 บรรทัด | ไม่ใช้ |
| 2 | 2 บรรทัด (2 ตัวเลือก/บรรทัด) | 3.4" |
| 3 | 1 บรรทัด 4 ตัวเลือก | 1.8" · 3.4" · 5.0" |

ตัวเลือกร้อยกรอง: คั่นวรรคหน้าหลังด้วย `\t` 1 ตัว + tab stop 2.8"

## Keep-together

ข้อสอบแต่ละข้อต้องอยู่หน้าเดียว — `keep_with_next = True` บนคำถามและตัวเลือก 1–3 · `keep_together = True` ทุกย่อหน้าของข้อนั้น Word จะดันทั้งข้อขึ้นหน้าใหม่เอง

## Zero-width space (จุดพังอันดับหนึ่ง)

ใส่ `\u200b` **ระหว่างคำไทยเท่านั้น** ห้ามแทรกกลางคำระหว่างพยัญชนะกับสระบน/สระล่าง/วรรณยุกต์/ทัณฑฆาต (`ิ ี ึ ื ุ ู ั ่ ้ ๊ ๋ ์`) — ถ้าผิดตำแหน่งสระจะหลุดจากพยัญชนะ

- `scripts/format_job03_example.py` — โค้ดงานจริงของ Job03 (ผูกกับโครงสร้างไฟล์นั้น: ย่อหน้า 208, รูปแบบเลขข้อ)
  - รัน: `py -3.12 scripts/format_job03_example.py [input.docx] [out.docx]` (ไม่ระบุ = `Job03.docx` / `Job03_Formatted.docx` ในโฟลเดอร์พ่อ)
  - ต้องมี `Job03.docx` เป็นอินพุต — สร้างไฟล์ตั้งต้นจาก `examples/Job03.json` ก่อน หรือใช้ไฟล์ข้อสอบของคุณเองในรูปแบบเดียวกัน
  - รูปแบบอินพุตที่ parse ได้: `1. [ว 1.1 ม.4-6/1] คำถาม...` + ตัวเลือก `ก.`/`ข.`/`ค.`/`ง.` หรือ `1)`–`4)` — **ห้ามใช้ `1.`** (จุด) นำตัวเลือก เพราะจะถูกอ่านเป็นข้อใหม่ (สคริปต์พิมพ์ WARNING ให้แล้ว)
- `scripts/legacy/` — คลังสคริปต์งานจริง 34 ไฟล์ (parse/จัดสมดุลตัวเลือก/ตรวจผล) ดู `scripts/legacy/README.md`
- `scripts/check_layouts.py` — ตรวจ layout/ความยาวตัวเลือก · `scripts/check_pages.py` — ตรวจจำนวนหน้าและข้อความต่อหน้า (ต้องมี PDF ที่ต้องการตรวจ)

`check_layouts.py` / `check_pages.py` หาไฟล์จาก `BASE_DIR` (โฟลเดอร์พ่อของ `scripts/`) — คัดลอกสคริปต์ไปวางในโฟลเดอร์งาน หรือแก้ path หัวไฟล์ก่อนรัน

## Pitfalls

1. **เชื่อจำนวนข้อที่ต้นฉบับพิมพ์** — ต้องคำนวณช่วง `(ข้อ X - Y)` เองจากรายการคำถามจริง
2. **ใส่ `\t` หน้าตัวเลือก** — ทำให้คอลัมน์เพี้ยน ให้ใช้ `left_indent`
3. **ลืม keep_with_next** — ข้อขาดกลางหน้า ผปค. ทักท้วง
4. **ฟอนต์เด้งเป็น Calibri/Angsana** — ยังไม่ได้ตั้ง `w:docDefaults` ครบ 4 script
5. **bold คำปฏิเสธในบทอ่าน** — ต้อง bold เฉพาะในตัวคำถาม
6. **ใส่เลขไทย** — ผิดกฎ ห้ามทุกกรณี
7. **ส่งออก PDF เอง** — ให้ `.docx` เท่านั้น เว้นแต่ผู้ใช้สั่ง
8. **ตัวเลือกในไฟล์อินพุตขึ้นต้นด้วย `1.`** — ชนกับเลขข้อ ใช้ `ก.` หรือ `1)` แทน
9. **ตรวจด้วยตาไม่ได้ถ้าไม่มี renderer** — เครื่องนี้ไม่มี LibreOffice แต่ใช้ Word COM ผ่าน `win32com` + `pymupdf` (ใน `py -3.12`) แปลง `.docx` → PDF → PNG ได้

- [ ] นับข้อทั้งหมด = ผลรวมช่วง `(ข้อ X - Y)` ในหัวข้อมาตรฐาน (รายงานตัวเลขจริง)
