# บันทึกข้อความราชการไทย (โรงเรียนพูลเจริญวิทยาคม)

สร้าง/แก้บันทึกข้อความภายในให้ถูกระเบียบงานสารบรรณและแบบของโรงเรียน ค่าพิกัด
และโครงสร้างในสกิลนี้สกัดจากเอกสารจริงของโรงเรียน (ดูตัวอย่างที่แนบมาใน `examples/`)

## When to Use (เมื่อไหร่ใช้)

- บันทึกข้อความไปราชการ / ขออนุมัติเดินทาง
- บันทึกข้อความรายงานผลการไปราชการ (ต้องมีภายในวันที่ระบุในบันทึกขอ)
- บันทึกข้อความส่งข้อสอบวัดผลปลายภาค/กลางภาค
- บันทึกชี้แจง (เช่น ชี้แจงการไม่ลงชื่อกลับ) · บันทึกการสอนแทน · บันทึกส่งเอกสาร

ไม่ใช้กับ: โครงการ (→ `thai-project-proposal`) · ข้อสอบ (→ `thai-exam-format`) · คำสั่ง/ประกาศโรงเรียน

## Prerequisites

- รันสคริปต์ด้วย `py -3.12` เท่านั้น (มี `python-docx 1.2.0` / `pythainlp 5.3.7` / `pymupdf 1.28.2`) — python 3.14 ของ Hermes ไม่มี python-docx
- ตราครุฑ: `assets/logo-krut.png` (สูง 1.5 ซม.)
- ตัวอย่างเอกสารที่ส่งจริง: `examples/` (แบบเปล่า / การสอนแทน / ส่งข้อสอบ)

## ลำดับเนื้อความ (3 ย่อหน้า)

1. **อ้างต้นเรื่อง** — ตามที่/ด้วย หน่วยงานใด แจ้งอะไร เลขที่หนังสือ ลงวันที่ เรื่อง ณ สถานที่ วันเวลา (คัดลอกเลขอ้างอิงจากหนังสือจริงเท่านั้น ห้ามแต่งเลข)
2. **สาระของเรื่อง** — สิ่งที่ทำ/ขอ/รายงาน พร้อมรายละเอียด จำนวน งบประมาณ ผู้เข้าร่วม
3. **ปิดท้าย** — `จึงเรียนมาเพื่อโปรดพิจารณา` (ขออนุมัติ) / `จึงเรียนมาเพื่อโปรดทราบ` (รายงาน) / `จึงเรียนมาเพื่อโปรดทราบและพิจารณา` (ส่งเรื่อง)

## Variant

| ประเภท | เนื้อความ | บล็อกลงชื่อ | เอกสารแนบ |
|---|---|---|---|
| ไปราชการ | ขออนุมัติ + ขอรับรองประโยชน์ + กำหนดวันรายงานผล | ผู้ขอ → ความเห็นรอง ผอ. → ความเห็น ผอ. | กำหนดการ/หนังสือเชิญ |
| รายงานผลไปราชการ | ตามที่ + สรุปสิ่งที่ได้ + ข้อเสนอ | ผู้รายงาน → รอง ผอ. → ผอ. | รูป/องค์ความรู้ (ถ้ามี) |
| ส่งข้อสอบ | อ้างข้อกำหนดฝ่ายวิชาการ + ส่งต้นฉบับตามแบบสรุป | หัวหน้ากลุ่มสาระฯ เท่านั้น | แบบสรุปการส่งข้อสอบ (หน้า 2) |
| ชี้แจง | เหตุการณ์ + สาเหตุ + แนวแก้ไข | ผู้ชี้แจง → ผอ. | หลักฐาน (ถ้ามี) |
| การสอนแทน | คาบ/วิชา/ชั้น + ครูผู้สอนแทน + เหตุผล | ผู้จัดทำ | ตารางสอน |

บล็อกความเห็นผู้บังคับบัญชา: ตาราง 2 คอลัมน์ (4.5 / 11.5 ซม.) ไม่มีเส้นขอบ · `ลงชื่อ` เยื้อง `left_indent = 1.45 ซม.` · ชื่อในวงเล็บเคาะนำหน้าให้ตรงกับเส้นประ

## รูปแบบ DOCX

- `TH Sarabun New` 16 pt เนื้อหา · บันทึกข้อความ 20 pt · สีดำ `#000000` · Line spacing 1.0 · Space before/after 0 pt (ยกเว้นเส้นคั่น/ช่องลงชื่อ)
- แทรก ZWSP ระหว่างคำไทยทุก run (`pythainlp.word_tokenize(engine='newmm')` แล้ว join ด้วย `\u200b`) — ห้ามแทรกกลางคำระหว่างพยัญชนะกับสระ/วรรณยุกต์/ทัณฑฆาต
- คลังเดิมตั้ง `noProof` + `hideSpellingErrors` + `lang=th-TH` (ต่างจากงานโครงการที่ห้าม `noProof` — งานคนละแบบ อย่าสลับ)
- อย่าใช้ Tab หรือเคาะวรรคจัดแนว ใช้ left_indent / first_line_indent / ตารางไม่มีเส้นขอบ
- สร้างเฉพาะ `.docx` ยกเว้นผู้ใช้สั่ง PDF ชัดเจน (ถ้าต้องพรีวิว ให้ render เป็นภาพเพื่อตรวจก่อนส่ง)

## ข้อมูลผู้ลงนาม

ไม่ hardcode ชื่อผู้ลงนาม · ใช้ชื่อ-ตำแหน่งตามที่ผู้ใช้ระบุในงานนั้น ถ้าไม่ระบุให้ใช้โปรไฟล์เจ้าของเครื่องจากสกิล `thai-doc` (`skill_view('thai-doc', 'references/user-profile-th.md')`)
ชื่อหัวหน้ากลุ่มสาระฯ ต้องสะกด **นายรามิล ปัญญพัทธ์** เท่านั้น (ห้าม ปัญญะพัฒน์ / ปัญญาพัทธ์)

## Pitfalls

1. **วันที่เป็น ค.ศ.** — ต้องเป็น พ.ศ. และวัน/เดือนต้องตรงกับหนังสืออ้างอิง
2. **แต่งเลขที่หนังสือ/ศธ** — ต้องคัดลอกจากต้นเรื่องจริง ถ้าไม่มีให้เว้นจุดไข่ปลา
3. **เรื่องตัวหนาทั้งบรรทัด** — มีแต่คำว่า `เรื่อง` ที่ bold
4. **ลืมบล็อกความเห็น ผอ.** ในบันทึกขออนุมัติ — แบบโรงเรียนมี 2 ชั้น (รอง ผอ. → ผอ.)
5. **เลขอ้างอิง/จำนวนเงินในเนื้อความไม่ตรงกับเอกสารแนบ** — ตรวจก่อนส่ง
