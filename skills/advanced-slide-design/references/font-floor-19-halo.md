# สเปกฟอนต์ขั้นต่ำ 19px + Stroke/Radiance (ล็อกโดยผู้ใช้ 2026-11-08)

ใช้ไฟล์นี้เป็นแม่แบบ: คัดลอกบล็อก CSS ไปวางบนสุดของ `<style>` ทุกงาน แล้วไล่ขนาดผ่านตัวแปรเท่านั้น
ห้ามแก้ `font-size` รายจุด — ถ้าต้องขยายทั้งระบบ ให้แก้ที่ `--t-*`

## 1. แคนวาส 1280×720 (16:9) — มาตรฐานที่ใช้จริง

| ตัวแปร | px | ≈ pt (PowerPoint) | ใช้กับ |
|---|---|---|---|
| `--t-micro` | **19** | 14.25 | eyebrow, เครดิตภาพ, เลขหน้า, footer — **พื้นล่างสุด ห้ามต่ำกว่า** |
| `--t-small` | 24 | 18 | ที่มาอ้างอิง, หน่วยนับ, `<small>` |
| `--t-body` | 32 | 24 | เนื้อความ (เป้าหมาย 32–36) |
| `--t-lead` | 36 | 27 | คำโปรย |
| `--t-h2` | 58 | 43.5 | หัวข้อ |
| `--t-num` | 96 | 72 | ตัวเลขนำ |
| `--t-quote` | 84 | 63 | ประโยคหลัก |
| `--t-display` | 132–150 | 99–112.5 | พาดหัวปก |

`1px = 0.75pt` เพราะแคนวาส 720px = 540pt
พื้น 19px = **2.64% ของความสูงแคนวาส** (ที่ 1920×1080 ใช้ ≈ 28–29px)

## 2. Stroke / Radiance

- ขนาด: **5px** หรือ **≈ 0.5 × ความหนาเส้นฟอนต์ (stem width)** — ตัวไหนมากกว่ากันใช้ตัวนั้น
- ฟอนต์เล็ก (19–32px): 5px คงที่
- ฟอนต์ใหญ่ (84px+): ขยายเป็น `em` (`--halo:0.3em`) ไม่งั้นเส้นจะบางจนหาย
- สี: **ตัดกับสีฟอนต์** ไม่ใช่ตัดกับภาพ และห้ามใช้สีเดียวกับฟอนต์
- ใช้เฉพาะเมื่อฟอนต์ทับภาพ/พื้นหลังที่ความสว่างไม่คงที่

```css
:root{
  --canvas-h:720px;
  --t-micro:19px; --t-small:24px; --t-body:32px; --t-lead:36px;
  --t-h2:58px; --t-num:96px; --t-quote:84px; --t-display:132px;

  --halo:5px;
  --halo-dark:rgba(12,20,16,.92);
  --halo-light:rgba(251,246,236,.95);
  --stroke-w:.045em;              /* ≈ 0.5 × stem */
}
.halo, .halo-lite{
  paint-order:stroke fill;
  -webkit-text-stroke:var(--stroke-w) var(--halo-dark);
  text-shadow:0 0 var(--halo) var(--halo-dark),
              0 0 var(--halo) var(--halo-dark),
              0 2px 6px rgba(0,0,0,.45);
}
.halo-lite{
  -webkit-text-stroke:var(--stroke-w) var(--halo-light);
  text-shadow:0 0 var(--halo) var(--halo-light),
              0 0 var(--halo) var(--halo-light),
              0 1px 4px rgba(0,0,0,.18);
}
/* ฟอนต์ใหญ่: ขยาย halo ตามขนาด — ใส่ class .halo-xl */
.halo-xl{ --halo:.3em; --stroke-w:.045em; }
```

## 3. เช็กลิสต์ก่อนส่งงาน

1. `grep -o "font-size:[0-9]*px" deck.html | sort -u` → ต้องไม่มีค่าน้อยกว่า 19
2. เปิด PNG ทุกสไลด์ด้วยตา 1 รอบ (หรือ vision) ดู halo ว่าหยัก/เลอะ หรือไม่
3. วัดว่าเนื้อหาล้นกรอบไหม — ถ้าล้น ให้ตัดคำ ไม่ใช่ลดฟอนต์
4. เอกสาร `.pptx` ที่ต้องส่งต่อ: 19px = 14.25pt, 32px = 24pt, 58px = 43.5pt
