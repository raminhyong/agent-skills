## 📌 1. การตั้งค่าหน้ากระดาษและระยะขอบ (Page Setup & Margins)

การกำหนดระยะขอบกระดาษ A4 (21.0 × 29.7 ซม.) ให้เลือกตามประเภทการใช้งานหลัก 2 รูปแบบ:

| รูปแบบเอกสาร | บน (Top) | ล่าง (Bottom) | ซ้าย (Left) | ขวา (Right) | วัตถุประสงค์หลัก |
| :--- | :---: | :---: | :---: | :---: | :--- |

## 🔤 2. ระบบฟอนต์และลำดับชั้นตัวอักษร (Typography Hierarchy)

### ฟอนต์มาตรฐานราชการและสากล
- **Font Family**: `TH Sarabun New` (หรือ `TH Sarabun PSK`)
- **สีตัวอักษร**: สีดำสนิท 100% (`#000000` / RGB: 0, 0, 0) ไม่มีสีเทาหรือสีเหลือบ

### การตั้งค่า Document Default Font (ระดับ XML)
ต้องกำหนดค่าระดับ `w:docDefaults` และ `Normal Style` ให้ครบทุก Script (`ascii`, `hAnsi`, `cs`, `eastAsia`) เพื่อป้องกันไม่ให้ Microsoft Word สลับกลับเป็นฟอนต์อื่น (เช่น Calibri, Angsana, Cordia) เมื่อมีการตัดแปะหรือแก้ไขข้อความ

### ลำดับชั้นขนาดตัวอักษร (Type Scale)
| ระดับชั้น (Level) | ขนาด (pt) | รูปแบบ | การจัดตำแหน่ง (Alignment) | ตัวอย่างการใช้งาน |
| :--- | :---: | :---: | :--- | :--- |
| **ชื่อเรื่องหลัก / ตราสัญลักษณ์** | **18 pt** | ตัวหนา (Bold) | กึ่งกลาง (Center) | ชื่อหน่วยงาน, ชื่อเอกสารหลัก |
| **หัวข้อหลักระดับที่ 1** | **16–17 pt** | ตัวหนา (Bold) | ชิดซ้าย (Left) | 1. ความเป็นมา, 2. วัตถุประสงค์ |
| **หัวข้อย่อยระดับที่ 2** | **16 pt** | ตัวหนา (Bold) | เยื้อง 1 Tab (0.5 นิ้ว) | 1.1 กลุ่มเป้าหมาย, 1.2 ระยะเวลา |
| **เนื้อหาบรรยายทั่วไป** | **16 pt** | ตัวปกติ (Regular) | เยื้อง 0.5 นิ้ว + Thai Distributed | ข้อความบรรยายเนื้อหาความเรียง |
| **หัวตาราง (Table Header)** | **14 pt** | ตัวหนา (Bold) | กึ่งกลาง (Center) | ชื่อคอลัมน์ในตาราง |
| **เนื้อหาในตาราง** | **13–14 pt** | ตัวปกติ (Regular) | ตัวเลข: กึ่งกลาง / ข้อความ: ชิดซ้าย | ข้อมูลสถิติ, รายการประเมิน |
| **คำอธิบายภาพ / เชิงอรรถ** | **13 pt** | ตัวเอียง (Italic) | กึ่งกลาง หรือ ชิดซ้าย | ที่มา: ..., รูปที่ 1 ... |

## 📏 3. ระยะบรรทัดและย่อหน้า (Line Spacing & Paragraph Rules)

1. **กฎ Zero Spacing**:
   - `Space Before`: **0 pt**
   - `Space After`: **0 pt**
   - `Line Spacing`: **1.0 เท่า (Single Line / 240 dxa)**  
   *(ภาษาไทยมีสระบน-ล่างและวรรณยุกต์ หากตั้ง Spacing เกิน 0 pt หรือใช้ Multiple Spacing จะทำให้ระยะบรรทัดห่างเกินจริงจนเอกสารดูโปร่งผิดปกติ)*
2. **การย่อหน้า (Indentation)**:
   - บรรทัดแรกของย่อหน้าใหม่ (First Line Indent): **0.5 นิ้ว** (1.27 ซม. หรือ 720 dxa)
   - การจัดแนวเนื้อหาบรรยาย: แนะนำใช้ **Thai Distributed** หรือ **Justify (ชิดขอบสองข้าง)** เพื่อให้ขอบข้อความด้านขวาเรียบเสมอกัน
3. **การเว้นระยะกรณีพิเศษ (Explicit Spacing)**:
   - ก่อนขึ้นหัวข้อใหญ่บนหน้าเดิม: เว้น Space Before **6–16 pt** (เพื่อแยกหมวดหมู่)
   - บรรทัดลงลายมือชื่อ: เว้น Space Before **6 pt** (เพื่อเว้นที่สำหรับจรดปากกา)

## ✂️ 4. การตัดคำภาษาไทยและการตรวจสะกด (NLP & Proofing)

1. **การตัดคำด้วย Zero-Width Space (`\u200b`)**:
   - ใช้เครื่องมือตัดคำภาษาไทย เช่น `PyThaiNLP` (`engine='newmm'`) แล้วแทรกอักขระ `\u200b` เพื่อให้ MS Word ตัดบรรทัดได้ตามคำที่มีความหมาย ไม่เกิดคำขาดกลาง
2. **⚠️ กฎเหล็กเรื่อง `\u200b` (ห้ามแทรกผิดตำแหน่ง)**:
   - **แทรกได้เฉพาะ**: ระหว่าง "คำต่อคำ" ภาษาไทยเท่านั้น
   - **ห้ามแทรกโดยเด็ดขาด**: ระหว่างตัวพยัญชนะกับสระบน (ิ, ี, ึ, ื, ั), สระล่าง (ุ, ู), วรรณยุกต์ (่, ้, ๊, ๋) และทัณฑฆาต (์) เพราะจะทำให้รูปสระกระเด็นแยกตัวและฟอนต์แสดงผลวิ่น
3. **การป้องกันเส้นหยักสีแดงใต้ข้อความ (No Proofing)**:
   - MS Word มักมองคำภาษาไทยเป็นคำผิดใน Dictionary ภาษาอังกฤษ ทำให้เกิดเส้นขีดหยักสีแดงรบกวนสายตา
   - แก้ไขโดยกำหนดคุณสมบัติใน Run Property:
     - `<w:noProof/>` (สั่งปิดการตรวจสะกดสำหรับ Run นั้น)
     - `<w:lang w:val="th-TH"/>` (กำหนดภาษาเป็นภาษาไทย)

## 📊 5. สถาปัตยกรรมตารางมาตรฐาน (Official Table Architecture)

1. **ความกว้างและการจัดตำแหน่ง**:
   - กว้างเต็มพื้นที่พิมพ์ (100% Alignment / Auto-fit to Printable Width)
   - จัดวางกึ่งกลางหน้ากระดาษ (Center Alignment)
2. **เส้นขอบตาราง (Borders)**:
   - เส้นเดี่ยวมาตรฐานสีดำสนิท (`#000000`) ความหนา **0.5 pt** (`w:sz="4"`) หรือ **0.75 pt** (`w:sz="6"`)
3. **ระยะขอบภายในเซลล์ (Cell Padding)**:
   - บน-ล่าง (Top / Bottom): `100–120 dxa` (~5–6 pt)
   - ซ้าย-ขวา (Left / Right): `140 dxa` (~7 pt)
4. **กฎเหล็กการป้องกันตารางแตกข้ามหน้า**:
   - `<w:tblHeader/>`: แถวหัวตารางต้องใส่แท็กนี้ทุกครั้ง เพื่อให้หัวตารางปรากฏซ้ำด้านบนสุดเสมอเมื่อตารางยาวเกิน 1 หน้า
   - `<w:cantSplit/>`: แถวข้อมูลทุกแถวต้องใส่แท็กนี้ เพื่อห้ามตัดแบ่งครึ่งแถวข้ามหน้าเด็ดขาด (ป้องกันตัวหนังสือในเซลล์ขาดครึ่งหน้า)

## 🛡️ 6. การควบคุมการขึ้นหน้าและการจัดกลุ่มข้อความ (Layout Flow Control)

1. **ป้องกันหัวข้อเดี่ยวท้ายหน้า (Orphan Headings)**:
   - ทุกย่อหน้าที่เป็น "หัวข้อ" (Heading 1, 2, 3) ต้องตั้งค่า **`keep_with_next = True`** เสมอ เพื่อให้หัวข้อย้ายตามเนื้อหาไปหน้าใหม่ ไม่ทิ้งหัวข้อไว้โดดเดี่ยวท้ายหน้า
2. **การตรึงกลุ่มข้อความ (Keep Together)**:
   - บล็อกข้อความที่ไม่ควรแยกหน้า เช่น ชุดคำถาม-ตัวเลือก, กล่องลงนาม, บันทึกสรุป ให้ตั้ง **`keep_together = True`**
3. **การขึ้นหน้าใหม่อย่างตั้งใจ (Page Break)**:
   - ใช้ Page Break ชัดเจนเมื่อขึ้น: ภาคผนวก, ใบงาน/แบบประเมิน, หรือข้อสอบส่วนถัดไป

## ✍️ 7. เครื่องหมายวรรคตอนและตัวเลข (Punctuation & Conventions)

1. **ระบบตัวเลข**:
   - ควรเลือกใช้ระบบใดระบบหนึ่ง **100% ตลอดทั้งเอกสาร** (แนะนำเลขอารบิก `0-9` สำหรับเอกสารวิชาการ ข้อสอบ และแผนงานสากล / หรือเลขไทยตามข้อกำหนดเฉพาะของระเบียบสารบรรณนั้น ๆ) ห้ามปะปนกัน
2. **เครื่องหมายทวิภาค (`:`)**:
   - ใช้เฉพาะ **ป้ายกำกับส่วนหัว (Header Labels)** เช่น `วันที่:`, `เรื่อง:`, `วัตถุประสงค์:`
   - **ห้ามใช้ `:` ฟุ่มเฟือย** ในประโยคความเรียงหรือท้ายหัวข้อบรรยายทั่วไป
3. **รายการและสัญลักษณ์แสดงหัวข้อย่อย (Bullets)**:
   - หากมีตัวเลขกำกับแล้ว (เช่น 1.1, 1.2): **ห้ามใส่เครื่องหมายขีดหน้าตัวเลข** (เขียน `1.1 เนื้อหา...` โดยตรง)
   - หากเป็นรายการย่อยที่ไม่มีตัวเลข: ให้ใช้เครื่องหมายขีดกลาง **`-`** เท่านั้น (First Line 0.5 นิ้ว, Wrap ชิดซ้าย 0 นิ้ว)
4. **เส้นประสำหรับเติมคำ / เขียนตอบ (Dotted Lines)**:
   - คำนวณความยาวจุดให้เต็มบรรทัดพอดี (เช่น หน้ากระดาษพิมพ์กว้าง 5.77 นิ้ว กำหนดมาตรฐานที่ **152 จุด** `.` × 152) ห้ามเกินจนจุดล้นไปขึ้นบรรทัดใหม่
5. **บล็อกลงลายมือชื่อ (Signatures)**:
   - เว้นระยะเส้นประลงชื่อให้พอดี (ประมาณ 40–56 จุด)
   - บรรทัดชื่อในวงเล็บ `( ... )` ควรเคาะเว้นวรรคนำหน้าประมาณ 10 เคาะ เพื่อให้แนวชื่ออยู่กึ่งกลางสมมาตรกับเส้นประด้านบน

## 💻 8. ฟังก์ชัน Python-docx ตัวช่วยระดับเทคนิค (Technical Helpers Snippet)

```python
import re
from docx.oxml import OxmlElement
from docx.oxml.ns import qn, nsdecls
from docx.oxml import parse_xml
from pythainlp import word_tokenize

def set_run_font_and_noproof(run, font_name="TH Sarabun New", size_pt=16, bold=False, color="000000"):
    """กำหนดฟอนต์ครบ 4 scripts, ปิดตรวจสะกด, และตั้งสีดำสนิท"""
    run.font.name = font_name
    run.font.size = Pt(size_pt)
    run.bold = bold
    rPr = run._r.get_or_add_rPr()
    
    # กำหนดฟอนต์ทั้ง ascii, hAnsi, cs, eastAsia
    rFonts = OxmlElement('w:rFonts')
    for attr in ('w:ascii', 'w:hAnsi', 'w:cs', 'w:eastAsia'):
        rFonts.set(qn(attr), font_name)
    rPr.append(rFonts)
    
    # ปิดเส้นหยักแดงตรวจสะกด
    rPr.append(OxmlElement('w:noProof'))
    
    # ตั้งภาษาไทย
    wLang = OxmlElement('w:lang')
    wLang.set(qn('w:val'), 'th-TH')
    rPr.append(wLang)
    
    # กำหนดสีตัวอักษร
    color_el = OxmlElement('w:color')
    color_el.set(qn('w:val'), color)
    rPr.append(color_el)

def safe_thai_tokenize(text):
    """ตัดคำภาษาไทยด้วย Zero-Width Space อย่างปลอดภัย ไม่ตัดสระ/วรรณยุกต์หลุดจากพยัญชนะ"""
    tokens = word_tokenize(text, engine='newmm')
    # แทรก \u200b เฉพาะคำต่อคำ
    return "\u200b".join(tokens)

def set_table_row_protection(row, is_header=False):
    """ป้องกันแถวตารางขาดครึ่งหน้า และกำหนดหัวตารางซ้ำอัตโนมัติ"""
    trPr = row._tr.get_or_add_trPr()
    trPr.append(OxmlElement('w:cantSplit'))
    if is_header:
        trPr.append(OxmlElement('w:tblHeader'))

def set_paragraph_zero_spacing(p):
    """ตั้งค่าระยะบรรทัด 1.0 เท่า และระยะก่อน/หลัง 0 pt"""
    p.paragraph_format.space_before = Pt(0)
    p.paragraph_format.space_after = Pt(0)
    p.paragraph_format.line_spacing = 1.0
```
